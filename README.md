# veiculosbr

Dados de veículo brasileiros em **R** e em **Python**, com o mesmo comportamento nas duas linguagens:

- placa antiga e Mercosul: conferir, formatar e converter;
- RENAVAM e chassi: conferir;
- preço FIPE, pelo modelo ou pela placa, mostrando todos os candidatos quando houver mais de um.

Em planejamento: ver [docs/plano.md](docs/plano.md).
